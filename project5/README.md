# Project 5: Brief — Seven-Day Study Plan

A reusable Agent Factory brief for delegating a one-week study plan to an AI assistant.

## Files

| File | What it is |
|---|---|
| [`brief/brief-template.md`](brief/brief-template.md) | The study-plan brief with placeholders |

## How the brief is built

- **Outcome:** a seven-day study plan for one subject.
- **Context:** hours available, time of day, and what is already finished.
- **Constraints:** a daily hour cap and one rest day.
- **Authority:** the AI picks the topic order but must ask before adding anything paid.
- **Deliverable:** a seven-row table (day, topic, time, resource).
- **Verification:** every resource needs a link that opens.
