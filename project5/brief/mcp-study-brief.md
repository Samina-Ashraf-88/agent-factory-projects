# Brief: 7-day MCP study plan

```
Outcome:      A study plan for building MCP (Model Context Protocol)
              servers for the next seven days, Mon 26 Oct to
              Sun 1 Nov 2026.
Context:      I have about 2 hours a day, in the evening (9-11 pm
              Pakistan time); the weekend can be the same. I've finished
              the Agent Factory lessons on briefs and the Delegation
              Record, I've used connectors and skills in Claude, and I
              know basic Python. I have not built an MCP server yet. By
              the end of the week I want a small working server of my
              own.
Constraints:  No more than 2 hours a day. One rest day. Topics build in
              order, from what MCP is to a working server.
Authority:    You choose the order of topics. Ask me before including
              anything paid (courses, books, subscriptions, paid API
              credits).
Deliverable:  A seven-row table: day (with date), topic, time, and the
              resource to use.
Verification: Every resource must have a link I can open.
```

## What was added beyond the template

- **Context** names a finish line (a working server by Sunday), so the topic order can be judged.
- **Authority** spells out what counts as paid, including API credits.
- **Deliverable** asks for the date as well as the day, so the rest day is easy to place.
