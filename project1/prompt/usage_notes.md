- **How to execute the Canva design via MCP**: Pass the JSON design brief from [canva_design_prompt.json](file:///D:/agent%20factory/pt-1/prompt/canva_design_prompt.json) to your Canva MCP server instance via the `create_design` or corresponding design endpoint.
