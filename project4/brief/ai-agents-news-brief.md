# Brief: weekly AI agents news

```
Outcome:      A summary of what happened in AI agents (agentic AI tools,
              MCP and connectors, major model and product launches) this
              week.
Context:      I follow this because I'm learning to build AI agents
              through the Agent Factory course and want to know which new
              tools and standards are worth trying. I already know the
              basics: what an agent is, what MCP does, and the main
              assistants (Claude, ChatGPT, Gemini). Skip explainers.
Constraints:  Only sources dated in the last seven days (14-21 Oct 2026).
              Say what you searched.
Authority:    You choose the sources. Say when two sources disagree
              instead of picking one silently.
Deliverable:  Eight bullet points at most, each with its source and date.
Verification: Mark anything that comes from a single source.
```

## What was added beyond the template

- **Outcome** names three sub-areas so "AI agents" doesn't sprawl.
- **Context** says "skip explainers" so the bullets go to news, not background.
- **Constraints** turn "last seven days" into exact dates, so out-of-window sources are easy to spot.
